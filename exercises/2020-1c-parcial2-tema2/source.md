# Source

- Original directory: `2020-1c/2doParcial/` in the parciales repository. The exam had two variants (Tema 1 and Tema 2); this exercise is Tema 2 (bumps and breaks: packers, heaviest vehicle / first to arrive criteria).
- Statement: `2do parcial - Enunciado Tema2.pdf` (5 pages, Spanish). Copied as `spec-original.pdf`. Note: its second section still says "Besides the cleaning" although this variant is about packing; the sentence was translated as it is.
- starting/: `ISW1-2020-1C-2doParcial-CodigoParaEmpezar.st` — the teaching staff's solution of the 1st midterm, re-categorized as `ISW1-2020-1C-2doParcial` (the statement says to extend "the solution proposed by the teaching staff for the 1st midterm (attached in the e-mail)"). Shared by both variants.
- solution/:
  - `ISW1-2020-1C-2doParcial-SolucionDeVideo.st` — the solution shown in the video (category `ISW1-2020-1C-2doParcial`).
  - `ISW1-2020-1C-2doParcial-SolucionDecoratorRobotShipper.st` — the alternative solution described in the README (category `ISW1-2020-1C-2doParcial-Solucion`).
  - `README.txt` — copied verbatim.
  IMPORTANT: both solution files implement the **Tema 1** variant (bleach/UV cleaners, lightest vehicle / last to arrive). The repository has no solution specific to Tema 2 (bubble wrap / carton box packers, heaviest vehicle / first to arrive). They were copied here because the README mentions both variants ("limpieza de productos/empaque de productos") and the two variants are mirror images of each other, so they serve as reference designs, not as literal Tema 2 solutions.
- README (translated): "Video of the solution: https://youtu.be/ez0kDLoeVLk. Comments on the alternative solution ISW1-2020-1C-2doParcial-SolucionDecoratorRobotShipper.st: The first item (product cleaning / product packing) avoids modifying the Trailer class by using a decorator to solve the problem. Additionally, the modification of the contamination/protection index is done through a message that reduces/increases that value by another one. This way of doing it avoids coupling the products with the cleaners, although it is on the verge of violating the product's encapsulation. We consider both ways valid anyway. Regarding the second item, this solution decides not to model the distribution center, and therefore not to give it responsibilities, and instead keeps only what is nothing more than a collection of vehicles. Who is in charge of answering the #ship:... message? In this case it is the robot, which is told it must ship its trailer and must choose some vehicle from the collection of vehicles to deposit it. Finally, the solution goes a little beyond what the exam statement asks, and tries to solve what happens if a robot without a trailer, or one that already shipped, is ordered to go take a product, or to close an order, or to ship again. This was not asked in the exam (I think its last paragraph made that clear), but we leave it in this solution as a curiosity."
- Removed from the statement: the course header, the "Reglas y normas a cumplir para parcial remoto" section (Zoom/breakout-room rules) and the "Entrega del parcial" section (file-out category and name, `.user.changes`, clean-image check, delivery e-mail, subject and confirmation).
