# Greeter

A `Greeter` greets a person by name. Add a way to greet formally: `greetFormally("Ada")` answers `"Good day, Ada."`. Keep the existing behaviour and its test working, and add a test for the new one.

Work in the Gradle project in the current directory; it is the only place your work is read from. The code is in src/main/java/app and the tests in src/test/java/app, both in the package app. Run the tests with `gradle test` (Gradle is on the PATH). Do not create files outside this project.
