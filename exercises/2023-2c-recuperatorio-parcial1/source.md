# Source

- Original directory: `2023-2c/Recuperatorio/` in the parciales repository (statement and solution) plus `2023-2c/2doParcial/` (initial code).
- Statement: `ISW1-2023-2C-Recuperatorio-Enunciado.pdf` (copied as `spec-original.pdf`, translated in `spec.md`). It is a single statement covering both make-ups. This exercise is the reduced scope given in the section "Those who have to make up the 1st midterm must" (create the game with the new two-team conditions, implement only the Soldier with Bayonet, move the players of each team in turns without handling players meeting at a position). The full scope is `2023-2c-recuperatorio-parcial2`. Both exercises share the statement and the code files.
- `starting/ISW1-2023-2C-2doParcial.st`: the initial code. The Recuperatorio directory has no separate initial file; the statement says the existing movement messages must keep being used and all existing tests must keep passing, and recommends moving "what is scattered about the player in `MineField`" into a new abstraction, so the starting code is the MineField solution of the 2nd midterm (`2023-2c/2doParcial/ISW1-2023-2C-2doParcial.st`, category `ISW1-2023-2C-2doParcial`, 18 classes, 119 methods, 40 tests). It was copied from that directory with its original name. The exam asks the solution to be filed out under the category `ISW1-2023-2C-Recuperatorio`; the `package` in `exercise.json` is the category of the starting code, as the brief asks.
- `solution/ISW1-2023-2C-Recuperatorio.st`: the only `.st` file in the Recuperatorio directory, the complete solution of the full scope (category `ISW1-2023-2C-Recuperatorio`, 25 classes, 225 methods, stamps `HAW 12/9/2023 - 12/11/2023`). There is no separate solution for the reduced scope; the relevant parts are `Player`/`SoldierWithBayonet`, `Team` (turn order with `CircularReadStream`), the reworked `MineField` and tests 41-53 (team creation, turns, winning, game over, dead players); tests 54-68 cover fights and armour restrictions that are out of this scope.
