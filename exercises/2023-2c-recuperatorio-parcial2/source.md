# Source

- Original directory: `2023-2c/Recuperatorio/` in the parciales repository (statement and solution) plus `2023-2c/2doParcial/` (initial code).
- Statement: `ISW1-2023-2C-Recuperatorio-Enunciado.pdf` (copied as `spec-original.pdf`, translated in `spec.md`). It is a single statement covering both make-ups: the full BattleField problem for those making up the 2nd midterm, and a reduced scope section ("Those who have to make up the 1st midterm must") for those making up the 1st midterm. This exercise is the full scope; `2023-2c-recuperatorio-parcial1` is the reduced one. Both share the statement and the code files.
- `starting/ISW1-2023-2C-2doParcial.st`: the initial code. The Recuperatorio directory has no separate initial file; the statement says the existing movement messages must keep being used and all existing tests must keep passing, and recommends moving "what is scattered about the player in `MineField`" into a new abstraction, so the starting code is the MineField solution of the 2nd midterm (`2023-2c/2doParcial/ISW1-2023-2C-2doParcial.st`, category `ISW1-2023-2C-2doParcial`, 18 classes, 119 methods, 40 tests). It was copied from that directory with its original name. Note that the exam asks the solution to be filed out under the category `ISW1-2023-2C-Recuperatorio`; the `package` in `exercise.json` is the category of the starting code, as the brief asks.
- `solution/ISW1-2023-2C-Recuperatorio.st`: the only `.st` file in the Recuperatorio directory. It is the complete solution (category `ISW1-2023-2C-Recuperatorio`, 25 classes, 225 methods, stamps `HAW 12/9/2023 - 12/11/2023`): the 40 original tests plus tests 41-69 for teams, turns, fights and armour restrictions; new classes `Player` with subclasses `SoldierWithBayonet`, `SoldierWithMachineGun`, `SoldierWithPistol` (double dispatch for fights, `wearArmorFrom:in:`), `Team` (uses `CircularReadStream` for the turn order), and `MineField` reworked to hold two teams, a current player and a clock.
- No Readme or video link was found in the directory.
- Removed from the statement: the "Entrega" (submission) section, the "IMPORTANTE" note, and the bullet stating that following the recommendations does not imply passing or failing (grading).
