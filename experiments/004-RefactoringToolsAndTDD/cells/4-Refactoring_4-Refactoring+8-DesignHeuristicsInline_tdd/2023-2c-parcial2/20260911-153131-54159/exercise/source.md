- Statement: `ISW1-2023-2C-Parcial-2-Enunciado.pdf` (copied as `spec-original.pdf`, translated in `spec.md`).
- No `starting/` directory: the statement asks to implement the game from scratch using TDD and does not mention any provided code.
- `solution/ISW1-2023-2C-2doParcial.st`: the only `.st` file in the directory. Although its name has no "Solucion" marker, it is a complete model (category `ISW1-2023-2C-2doParcial`, 18 classes, 119 methods, author stamps `HAW 11/27/2023 - 12/7/2023`): `MineFieldTest` with 40 tests, `MineField`, the field elements (`FieldElement`, `EmptyFieldElement`, `NotEmptyFieldPosition`, `Mine`/`LowPowerMine`/`HighPowerMine`, `ArmorRack`, `Tunnel`) and the armours (`Armor`, `NoArmor`, `LightArmor`, `HeavyArmor`). It was therefore treated as the teacher's solution, not as initial code. It is also the code on which the Recuperatorio of this semester builds (see `2023-2c-recuperatorio-*`).
