# ISW1-AutomaticCar (Driving Assistant)

The company has decided to invest in a car driving assistance system (DrivingAssistant). This
system is a real-time system that keeps generating actions according to what is read from the
sensors and the type of assistance chosen. The sensor-reading and decision-making period has not
been decided yet, so the assistant is expected to know how to answer a message (for example
`#tick`) that will later be sent with whatever frequency is decided.

Because it is a critical system, it is extremely important that it be well tested; in short, that
it consider all the possible functional cases tested and that there be no untested code.

The assistant must interact with two systems:

- The sensor system: it has two sensors and is in charge of the "input" of information.
- The driving system: it is the one that has to be told which actions to perform.

The sensor system has two sensors:

- Speed sensor: answers the current speed. For example: `100*kilometer/hour`
- Front proximity sensor: answers the distance to an object located ahead. For example:
  `25*meter`

The actions that the driving system can be asked to perform are:

- Set the proximity beep to danger, warning or off (`dangerProximityBeep`,
  `warningProximityBeep`, `turnOffProximityBeep`)
- Connect or disconnect the throttle (`connectThrottle`, `disconnectThrottle`)
- Keep a desired speed (`keepSpeedAt:` ...)
- Brake or stop braking (`applyBrakes`, `releaseBrakes`)

The front proximity sensor is used to define the braking distance needed in order not to crash if
an object appears ahead. The minimum braking distance (distancia mínima de frenado, DMF) is
`speed^2/(180000*kilometer/(hour^2))`. For example, if the speed is `100*kilometer/hour`, the
DMF is: `(100*kilometer/hour)^2 / (180000*kilometer/(hour^2))` → approx `55.55 * meter`

The assistant must take into account three distance zones:

- Danger zone: when the distance to the object is between 0 meters and the DMF inclusive.
- Warning zone: when the distance to the object is greater than the DMF and less than or equal to
  DMF*2.
- Safe zone: when the distance to the object is greater than DMF*2 or there is no object ahead.

The assistant can work in three modes: Manual, Automatic and Assisted-Manual. The assistant's
behaviour must vary according to the selected mode in the following way:

- Manual
  - Distance sensor:
    - If in the danger zone, it must set the proximity beep to danger.
    - If in the warning zone, it must set the proximity beep to warning.
    - If in the safe zone, it must turn off the proximity beep. Same if there is no object in
      front.
- Automatic: in automatic mode the target speed to keep must be indicated.
  - Distance sensor:
    - If in the danger zone, press the brakes, disconnect the throttle and set as target speed
      `10*kilometer/hour` less than the current one. The case in which it becomes negative need
      not be considered.
    - If in the warning zone, disconnect the throttle, not be braking, and set as target speed
      `5*kilometer/hour` less than the current one. The case in which it becomes negative need
      not be considered.
    - If in the safe zone or there is no object ahead, it must keep the target speed.
- Assisted-Manual: it is the combination of manual and automatic, therefore the target speed to
  keep must be indicated.
  - Distance sensor:
    - Combine what the manual and automatic modes do.

When the car is turned on, the speed is `0*kilometer/hour`, the proximity beep is off, the
throttle is connected, not braking, and the target speed is defined by the driving mode (in the
case of manual mode, there is no target speed). HINT: this is a good case to start with :-)

The case of switching from one driving mode to another need not be considered; one always starts
with a driving mode and keeps it.

It must be assumed that the sensors always answer valid values. CLARIFICATION: in a real system
one cannot assume that the sensors will work well or that the actions will be performed without
contradiction.

Solve the exercise.

Hints:

- The events generated by the sensors can be modelled with `ReadStream`. For example, for the
  speed sensor one can use `ReadStream on: { 100*kilometer/hour. 110*kilometer/hour }`.
- There is no problem in turning the beep off again if it is already off, or connecting the
  throttle again if it is already connected.

## Clarifications made during the exam

- There are three kinds of speed:
  - The current speed, which is the one answered by the sensor.
  - The target speed, which is configured when creating the Automatic and Assisted-Manual modes.
  - The target speed that is indicated to the driving system by means of the message
    `keepSpeedAt:`. A better way to call it would be desired speed.
- When in Automatic mode and there is an object in the safe zone or there is no object in front,
  the mode's target speed must be set as the desired speed. The throttle must also be connected
  and it must not be braking.
- The problem can be thought of with the metaphor where the assistant is the person driving, the
  speed sensor is the speedometer, the distance sensor is what one sees ahead, and the driving
  system would be something like a smart car.
