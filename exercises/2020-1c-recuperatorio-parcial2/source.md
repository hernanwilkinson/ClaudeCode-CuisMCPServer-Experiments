# Source

- Original directory: `2020-1c/Recuperatorios/` in the parciales repository (it holds the two make-up exams of the semester; this exercise is the general make-up, which extends the second-midterm model).
- Statement: `IS1-1C2020-Recuperatorio.pdf` (4 pages, Spanish). Copied as `spec-original.pdf`.
- starting/: `ISW1-2020-1C-2doParcial-SolucionDeVideo.st`, copied from `2020-1c/2doParcial/`. The README says "To do the exercise you have to start from the solution of the 2nd midterm", and the solution file of this exam is built on top of that particular solution (it keeps its classes `CleaningTrailer`, `Cleaner`, `DistibutionCenter`, `CargoVehicleSelectionCriteria`, etc.). Its category is `ISW1-2020-1C-2doParcial`, while the exam expects the work in `ISW1-2020-1C-Recuperatorio`.
- solution/:
  - `ISW1-2020-1C-Recuperatorio.st` — treated as the solution because it contains the new behaviour asked by the statement (`MountableTrailer`, `SingleTrailer`, `MountableTrailerTest`, `CargoVehicleTest` with carried vehicles) on category `ISW1-2020-1C-Recuperatorio`, and the README describes it as "the final solution".
  - `README.TXT` — copied verbatim.
- README (translated): "The final solution has a couple of renames and message categorizations that are not in the video. To do the exercise you have to start from the solution of the 2nd midterm. I just saw that there is a final part of the video where I refactor the solution categorizing methods and fix a couple of errors that there were, which was not left... Anyway the code does include those modifications". No video link is given in the directory.
- Removed from the statement: the course header, the "Reglas y normas a cumplir para recuperatorio remoto" section (Zoom/breakout-room rules and the consultation spreadsheet link) and the "Entrega del recuperatorio" section (file-out category and name, `.user.changes`, clean-image check, delivery e-mail, subject and confirmation).

- `starting/ISW1-2020-1C-2doParcial-SolucionDeVideo.st` was ISO-8859-1 encoded; it was re-encoded as UTF-8 so Cuis 7.9 files it in correctly. The verbatim copy is `starting/original/ISW1-2020-1C-2doParcial-SolucionDeVideo.st`.
