# Experiments

One directory per hypothesis or idea tried, numbered in the order they were started:
`NNN-Description/`. Each has a `README.md` with the question, the design, the results and the
conclusion, and a `cells/` directory with one subdirectory per cell of the matrix
(`<scenario>_<config>_<technique>`), then one per exercise, then one per run
(`<YYYYmmdd-HHMMSS-pid>`). Matrices run with `scripts/5-runMatrix.sh` also have `plan.txt`,
`parameters.json`, `logs/`, `runs.txt`, `results.json` and `table.md`; rebuild the last two with
`scripts/matrix-table.py experiments/<experiment>`.

Single runs are started with `scripts/2-runCell.sh --experiment NNN-Description ...` and land in
the same layout; write the README by hand for those.
