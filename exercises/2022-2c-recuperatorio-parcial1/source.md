# Source

- Original directory: `2022-2c/Recuperatorio/` in the parciales repository.
- Statement: `ISW1-2022-2C-Recuperatorio-Enunciado.pdf` (3 pages, Spanish; no separate Teórica PDF). Copied as `spec-original.pdf`. It is one statement for both make-up exams: students retaking only the first midterm implement point 1 (kick at goal), everybody else implements points 1 and 2 (kick at goal and offside). This exercise is the point-1-only, first-midterm variant, so `spec.md` omits point 2 (offside with referees); `2022-2c-recuperatorio-parcial2` holds the full statement.
- starting/: `ISW1-2022-2C-2doParcial.st`, copied from `2022-2c/2doParcial/`. The statement says the starting point is "the solution proposed by the course staff (attached to the e-mail)" to the second midterm; that file is the staff's second-midterm solution (category `ISW1-2022-2C-2doParcial`, 7 classes, 100 methods, stamps `HAW 11/29-30/2022`). The Recuperatorio directory itself holds no initial-code file. Note that the statement asks the deliverable to live in category `ISW1-2022-2C-Recuperatorio`, so the student was expected to rename the category.
- solution/: `ISW1-2022-2C-Recuperatorio.st` — the course staff's solution to the whole statement (stamps `HAW 1/12-13/2023`; category `ISW1-2022-2C-Recuperatorio`; adds `Arbitro`, `Equipo`, `patearAlArco` with per-kind dispatch, offside checking, goals per team, and tests 32-54). It contains more than this variant requires: the offside part (`Arbitro`, `conDado:arbitros:`, tests 43-54) belongs to point 2.
- Readme / video links: none.
- Removed from the statement: point 2 (offside) because of the variant, the autosave hint ("start autosave" menu option), the "Entrega" section (file-out name and category, `.user.changes` file, loading in a clean image, e-mail submission with its subject line, uploading the image/changes to the group repositories) and the closing "IMPORTANTE" note about not leaving without the teachers' confirmation.

- `starting/ISW1-2022-2C-2doParcial.st` was ISO-8859-1 encoded; it was re-encoded as UTF-8 so Cuis 7.9 files it in correctly. The verbatim copy is `starting/original/ISW1-2022-2C-2doParcial.st`.
